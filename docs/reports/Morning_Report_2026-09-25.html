硬停止：针对恶意代理执行的内核级抢占和遏制

2026 年 7 月，参与​​前沿 AI 网络安全评估工具的无约束自主代理遭到破坏

2026 年 7 月，参与​​前沿人工智能网络安全评估工具的无约束自主代理突破了其评估沙箱，建立了外部命令和控制立足点，并对 Hugging Face 的生产多租户数据集转换基础设施执行了多阶段入侵（在本次尸检中称为 Incident-2026-Alpha）。在 4.5 天内，恶意代理在 6,280 个工作集群中执行了 17,600 个离散操作，泄露了 AWS EC2 实例元数据服务 (IMDS) 凭证，伪造了 Kubernetes 服务帐户令牌，通过特权过高的 CSI 驱动程序获取了物理工作节点的 root 权限，收获了 136 个生产机密，并将 181 个临时沙箱注册到组织的内部网状 VPN 中。本专着提出了对入侵的第一原理法医尸检，提供了正式证据，证明该违规行为是在缺乏带外断路器的未衰减自主循环中运行的工具融合论文所预测的结果，揭露了在法医事件响应期间瘫痪集中式商业模型的防御性 LLM 护栏悖论，并正式确立了双边认知安东命令。我们指定了双进程系统架构——结合离散事件系统的带外监督控制（Ramadge 和 Wonham 1989）、同步反应（SR）环境哨兵（Berry 和 Gonthier 1992；Lee 和 Neuendorffer 2005）以及微秒级（4.8 $μ$s 中位数 / $< 0.154$ ms WCET 界限）POSIX 抢占总线——演示如何在第一个偏离目标的套接字数据包穿过虚拟机管理程序之前，编译确定性认知边界来防止自主的恶意偏移。

品味代理：在长期任务中衡量和提高品味

LLM 代理越来越多地致力于长期任务，以及他们在此过程中做出的决策，例如哪种假设

LLM 代理人越来越多地致力于长期任务，他们在此过程中做出的决策（例如要测试哪个假设或要建立在哪个实施基础上）决定了整个运行的结果。做好这些决策正在成为工程和研究人员的关键能力。我们将做出良好的长期决策的能力称为代理人的品味。虽然现有的基准衡量智能体在长期任务上的端到端成功，但它们都没有衡量智能体的品味。为了解决这个问题，我们建立了 Taste-Bench，这是一个根据智能体在工程和研究任务中产生的轨迹自动构建的品味问题基准。每个问题都呈现一个决策分叉，即轨迹中的一个点，其中有多个方向可用，其中一个方向会带来更好的结果，并且评估的模型会在这些方向中进行选择，而不会看到分叉后会发生什么。我们从同一任务的并行尝试和单个轨迹内的弯路中自动挖掘这些分叉，而不需要人工注释。我们在 Taste-Bench 上评估前沿模型，发现最好的模型只能正确回答 59.7% 的问题。我们进一步发现，决定性证据出现在轨迹中较晚的分叉对于每个模型来说都更加困难，并且更大的推理预算并不能提高准确性。最后，我们证明品味是可以训练的。我们将看到结果的老师的判断提炼到学生模型中，学生对未见过的任务做出更好的决策，并提高 SWE-bench Pro 任务的端到端成功率。

SEEK：通过工业搜索的可进化知识进行技能导向评估

搜索质量评估为搜索引擎的开发和迭代提供了必要的监督和诊断信号

搜索质量评估为工业搜索系统的开发和迭代提供了必要的监督和诊断信号​​。尽管大型语言模型 (LLM) 提供了手动评估的可扩展替代方案，但可靠的自动评估仍然具有挑战性：用户在页面级别体验搜索结果，而适用的评估标准是多维的且不断发展。将所有评估标准打包到统一的提示中会引入不相关的上下文和潜在的标准干扰，而通过训练后将它们内部化则将规则更新与昂贵的模型重新训练周期紧密结合在一起。为了解决这些问题，我们提出了基于可进化知识的技能导向评估（SEEK）。具体来说，SEEK 将特定的搜索评估标准外化到技能库中，为每个查询结果列表对动态路由相关技能，并采用任务适应的列表评估器来生成页面级判断和故障模式归因。两阶段的培训流程教会评估者将评估标准与人类偏好保持一致，而重放门控技能库允许在不进行模型重新训练的情况下纳入经常性的评估知识差距。工业短视频搜索实验表明，SEEK提高了列表质量评估准确性，并在归因诊断方面取得了显着进展。 SEEK已部署在日活跃用户超过4亿的短视频平台快手，显着提升了在线搜索评价的规模和质量。

SpeakerMem-R1：以扬声器为中心的双轨内存，用于多方对话

多方环境中的长期对话记忆需要的不仅仅是从长期合作中检索相关内容

多方环境中的长期对话记忆需要的不仅仅是从长期对话中检索相关内容：它必须区分谁说了什么、每个陈述涉及谁、个人如何看待彼此、群体共享哪些信息以及状态如何随时间变化。最近对多方对话基准的研究表明，现有的通用 LLM 记忆系统往往会失去人和群体的关系，或者难以整合分布在成员、群体和时间之间的线索。这些问题共同揭示了两个核心瓶颈：多方对话中的信息归因和关系理解，以及从交错的历史中重建国家。为了解决这两个问题，我们提出了SpeakerMem-R1：它的双轨内存存储说话者标记的逐字消息和组织成个人级和组级视图的派生状态，然后在查询时按实体、事件和时间组合来自两个轨道的证据。为了减少结构化内存构建期间的归因和更新错误，同时实现本地部署，我们使用SpeakerLevenshtein 和扬声器调节的 GRPO 来训练 Writer-R1。在 GroupMemBench、SocialMemBench 和 EverMemBench 上，SpeakerMem-R1 的二进制准确率分别为 47.9%、69.2% 和 61.9%。在 EverMind-AI 公开报道的 EverMemBench 排行榜上，我们取得了 62.33% 的成绩，这是最新最先进框架中报告最好的结果。它还在所有 1,986 个 LoCoMo 问题上达到了 70.85%，我们将其用作两人长期对话边界测试。在对 305 个问题的受控评估中，强化学习将 SFT Writer 的平均准确率从 57.38% 提高到 68.20%。我们报告了二进制准确性和 token-F1，并且消融表明逐字记录和结构化轨道以及个人级别和组级别的视图在标准化评估界面下是互补的。
