计算机图形学是建立在代码之上的。大型语言模型 (LLM) 代理现在可以生成图形代码并通过各种反馈迭代地完善它。这一功能为计算机图形学的潜在新范式打开了大门，图形算法越来越多地围绕代理系统构建，以自动执行逐渐复杂的任务。在过去的几年里，代理图形的研究在各种任务中迅速扩展。这种快速增长使得手工文献综述越来越难以跟上新发展的步伐。与此同时，在这些任务中，类似的想法经常使用不同的术语来描述，这使得系统地理解该领域的工作进一步复杂化。在本报告中，我们通过两项贡献应对这些挑战。首先，我们引入了一个统一的分类法，用于描述不同计算机图形任务中的代理系统的特征。其次，我们开发了一个代理文献系统，可以帮助人类研究人员大规模分析现有和新发表的论文。在这些贡献的基础上，我们分析了新兴的研究趋势，并讨论了跨图形任务协调代理和工具、设计人机协作的界面和表示、维持长期规划和细化以及可靠地评估交互式图形系统等方面的开放挑战。

FlowTranslator：具有基于流的编辑功能的免培训图像内机器翻译

图像内机器翻译 (IIMT) 用翻译替换图像中的文本，同时保留周围的视觉效果

图像内机器翻译 (IIMT) 用翻译替换图像中的文本，同时保留周围的视觉上下文。现有的特定任务模型取得了令人信服的性能，但在翻译前后需要大量配对训练图像。由于先进的文本到图像（T2I）模型已经达到了多语言文本生成的实用水平，我们认为这种能力可以转移到 IIMT 和现有的 FlowTranslator。它是一个免训练的 IIMT 框架，首先采用 OCR 模型和 LLM 生成翻译提示，然后将其注入到基于 T2I 的扩散模型中。为了优化翻译文本的准确和自然生成，我们引入了两种轨迹控制：区域耦合释放（RCR）在轨迹早期部分去相关文本区域内的目标分支噪声，而耦合扩展（CE）则放大了轨迹中出现的编辑位移。在 EasyOCR 回读协议下，FlowTranslator 的平均 PRIM BLEU 和 COMET 分数分别为 20.6 和 57.2，大大优于基于强大训练的基线 UniTranslator。在翻译成中文的更具挑战性和真实感的全图像 ScenePair 照片上，它达到了 40.1% 的精确匹配精度，并超越了现有的编辑系统，其中一些系统仅解决文本渲染阶段而不是完整的 IIMT 任务。这些结果将基于流程的编辑确立为 IIMT 强大的、完全免训练的基线。

波力：迈向光速流媒体视频生成

实时长视频生成需要具有一致的外观和自然运动的连续输出。现有块

实时长视频生成需要具有一致的外观和自然运动的连续输出。现有的分块自回归方法在生成效率和长视频质量方面面临挑战：即使是一步去噪，序列化去噪和历史缓存刷新也需要两次前向传递，而较长的推出时间会降低质量并导致相机漂移。我们提出了 Wave Forcing (WF)，它通过多步去噪来共同设计连续视频输出的生成、训练和执行。 WF 使用逐块因果注意力在去噪完成之前访问更早、更干净的块，并在全模型副本上分布交错的去噪和缓存刷新阶段，以实现 1F1C：管道填充后，每个并发前向轮输出一个块。为了使模型适应这种连续生成过程，我们开发了一个三阶段训练程序，该程序连续引入混合噪声去噪、运动监督和使用自生成历史的因果适应。为了有效地执行此过程，Wave Runtime (WaveRT) 使用 Wave Parallelism (WP) 进行早期 K/V 交付和通信计算重叠，以及优化的内核和流水线 VAE 解码。在 Wan2.1-T2V-1.3B 上的实验表明，5 步 WF 保持了与 Rolling Forcing 相当的整体质量，同时在短视频和长视频上实现了更高的动态程度。我们的系统效率实验表明，4 步 WF 在 8 个 H200 GPU 上实现了 147.6 DiT FPS 和 134.8 端到端 FPS，产生了单 GPU 端到端吞吐量的 7.07 倍。在仅 DiT 测试中，使用匹配的 SageAttention+W8A8 后端、降噪步骤和 GPU 数量，WP 在六个模型规模 (1.3B-14B) 中提供的吞吐量是 Ulysses 和 Ring 上下文并行基线中较快者的 2.53 倍。

回答对地球观测 (EO) 档案的地理查询需要在严格的时空约束下解决联合检索和推导问题。现有的 LLM 代理无法将观测项目接地或遭受搜索空间爆炸的影响。我们提出了 OSGR，一个两阶段框架，将这种搜索分解为离线符号概念推导和在线关系条件基础。 OSGR 利用离线观察支持图在概念层面推导有效的目标到结果支持路径，并应用时空兼容性内核来实例化接地观察项集。在 Earth-Bench 和 DisasterM3-Reason 上，OSGR 将 GPT-4o 精度从 49.3% 提高到 63.7%，同时将执行步比从 2.9 降低到 2.5。
