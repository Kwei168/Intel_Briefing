Tree-Ising：通过位级 Ising 编辑修复语言模型

Takehi 等人在最近的 MIT 工作中引入了权重空间编程，它使前沿 LLM 代理能够读取网络的权重并编写修复。他们的 GPT-6 Astra 代理使用 158 次代理轮次、8970 万个令牌和 50 个前向传递请求，纠正了 Qwen3.5-0.8B 的无梯度推理循环。我们的方法 Tree-Ising 将此修复视为模型自身 BF16 权重的稀疏离散优化问题。前向统计定义了一个目标，该目标削弱循环方向，加强结论方向，并保留该层在生产性代币上的输出。在状态树表示中，无损 BF16 存储作为特例，可接受的编辑是符号翻转和指数移位，保留所有共享组指数和尾数。我们将这个目标精确地分解为独立的 QUBO (Ising) 问题，每个输出行一个，我们使用模拟退火或量子启发的模拟分叉在 GPU 上解决该问题。在代理的两层上，Tree-Ising 在 MATH-500 上取得了 54.6% 的成绩，优于相同评估协议下代理的编辑 (51.7%)，而基础模型的得分为 7.9%。模拟分叉求解器的修复率在统计上无法区分，为 55.1%。两个求解器在所有五个数学基准测试中的表现均优于代理编辑，在校正多重比较后，MATH-500 和 GSM8K 上的统计显着改进。我们的方法将权重减少了 13% 到 17%，并将 BF16 位翻转减少了 2.2 到 2.3 倍。它只需要四个前向传递请求和零个 LLM 令牌，退火配方花费的 GPU 时间约为 0.90 美元。在 Qwen3.5-2B 上，仅使用基本模型选择层和剂量，相同的方法将贪婪的 GSM8K 准确率从 21.6% 提高到 69.4%。作为概念验证，我们在 IBM Heron 处理器上使用 QAOA 执行八变量修复子问题。

在大型自然图像集合上预训练的基础模型越来越适合医学图像分割，期望它们将取代针对每个任务训练的模型。然而，大多数比较都使用来自训练分布的数据和单个特定于任务的基线，其配置很少合理，因此在新临床站点提供的性能证据有限。目前还不清楚基础模型的多少部分必须进行调整，以及是什么决定了这一点。我们采用了基础模型 DINOv2，其策略范围从仅调整其偏差项到全面微调，并将其与从头开始训练的 U-Net 和 ResU-Net 进行比较。实验涵盖结肠镜检查、乳腺超声检查和皮肤镜检查，并对来自培训源的保留数据和来自其他机构的独立数据集进行测试。改编后的基础模型在每个外部数据集上都具有更好的泛化能力。在训练分布中，当训练数据丰富时，特定任务模型仍然具有竞争力，并且更精确地描绘边界，而基础模型更经常错过小病变。只有一小部分基础模型需要自适应，并且所需的容量由成像领域而不是自适应方法决定。还发现广泛使用的息肉测试集复制了另一个基准的图像。因此，当模型必须跨站点工作并在目标域上选择容量时，基础模型的适应是有必要的。

少步采样降低了流视频生成的成本。分布匹配蒸馏 (DMD) 使用单独的假分数网络来监督几步生成器，该网络增加了训练内存和计算，并且必须跟踪不断发展的生成器。我们通过使用条件转换来估计生成器内生成的分布的速度场，将 APEX 扩展到流视频。原始文本条件选择生成，而移位条件选择使用相同参数的假估计。这去除了独立的假网络，同时保留了《S2-Avatar》的冻结参考老师、Self-Replay Forcing 和感知正则化。我们使用每个块的三个主干评估和一步空间 Refiner 来评估 180 秒视频的 APEX，并进行 70 例人体研究和 320 例 StreamAV-Bench 比较。与 S2-Avatar 相比，APEX 在渐进式轨道上实现了更高的视频指令完成度（3.856 比 3.831），并且在两个轨道上实现了更高的视觉美感（0.641898 比 0.632606）。人类评分者在指令遵循方面最看重 APEX，净偏好度增加 30.0%，其次是一致性和视频质量，各增加 4.3%。运动质量有利于 S2-Avatar，视听同步主要受到限制，可用性没有变化。匹配训练设置下的单独测量显示，与 DMD 相比，每个 GPU 分配的 GPU 内存峰值降低了 4.4%，平均迭代时间缩短了 9.2%。
