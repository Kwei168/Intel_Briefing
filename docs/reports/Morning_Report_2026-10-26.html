歌唱情感识别主要依赖于深度学习模型，这些模型可以实现强大的性能，但对驱动情感的声音特征的洞察力有限，通常会忽视歌声作为一个独特的信号。我们提出了一个可解释的歌唱情感识别框架，使用一组紧凑的歌唱特定描述符，涵盖韵律、频谱特征、语音和声乐技巧。为了解码模型决策并将预测与可测量的声学现象联系起来，我们采用 SHAP 并应用 GRAD-CAM 来定性评估学习到的声乐技术表示。评估表明，歌唱特定的特征减少了歌手之间的差异，而声乐技术描述符则提供了对歌唱表达的可解释的见解。此外，对 VocalSet 的域外评估揭示了情感表达和真实技术执行之间有趣的关联。该分析强调颤音和咽部技术是情感传递的显着线索，SHAP 表明颤音与发音速率相关。这些发现强调了特定领域特征对于可解释的歌唱情感分析的价值。

通过组合编辑优先蒸馏将图像编辑为可重复使用的图层

高质量的图像编辑需要精确修改目标区域，同时保留不相关的reg内容

高质量的图像编辑需要精确修改目标区域，同时保留不相关区域的内容。现有的编辑模型产生扁平化的输出，限制了精确的本地操作和图层重用，而分解方法通常独立于指令驱动的编辑来优化图层恢复。为此，我们引入了 LayerEditor，这是一个统一的框架，它将指令引导的图像编辑与可重用 RGBA 层的可控生成结合起来。其核心是，上下文 RGB-Alpha 令牌建模在单个令牌序列中联合表示已编辑的画布和 RGB-Alpha 层的有序序列，从而实现对各个层内容的语义编辑和显式控制。为了在适应分层输出期间保留预训练模型的编辑能力，我们提出了组合编辑优先蒸馏，它将其编辑转移到编辑的画布和由预测层组成的图像之前。为了支持训练和评估，我们构建了 LayerEditor-100K，这是一个具有有序 RGBA 图层注释的大规模配对图像编辑数据集，并引入了分层编辑的专用基准。大量实验表明，LayerEditor 在生成精确的 RGBA 图层的同时保持了强大的编辑保真度，支持灵活的图层级操作和多层分解。

LGMT：测试法学硕士逻辑推理可靠性的工具

大型语言模型 (LLM) 越来越多地充当现代软件系统中的推理组件，但这种模型

大型语言模型 (LLM) 越来越多地充当现代软件系统中的推理组件，但当以等效形式重述同一问题时，正确回答逻辑查询的模型可能会自相矛盾。静态基准测试单独评估查询，因此无法暴露此类不一致之处。为了解决这个限制，我们提出了 LGMT，这是一种开源工具，可以通过基于一阶逻辑的变形关系来检测推理的不一致。给定前提-结论形式的源测试用例，LGMT 会生成逻辑上等效的后续用例，并检查模型的蕴含预测是否在整个对中一致，而无需真实标签。该工具提供 20 个内置变形关系，支持由 Z3 定理证明器验证的自定义关系，并从 CLI 或 Web 工作室运行，包括不需要 API 密钥的离线模拟模式。在 6 个广泛使用的 LLM 中，对 3,091 个变质组的捆绑基准进行分析，LGMT 显示不一致率从 20.84% 到 29.44% 不等。 LGMT 可在 GitHub 上公开获取：https://github.com/MaxwelsDonc/lgmt-tool，演示视频位于 https://youtu.be/gou4opptu1U。
