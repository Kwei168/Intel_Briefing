解耦预测决策：智能体的共享条件预测器

代理决策取决于部署观察揭示的经验关系，并且单独的任务描述可能会导致

代理决策取决于部署观察揭示的经验关系，而任务描述本身可能无法解决。我们引入了解耦预测决策（DPDM），这是一种利用共享预训练学习器将异构代理决策制定为条件预测的架构。语言模型提供当前和历史记录的语义表示，而通用条件预测器则根据表示的证据预测任务定义的目标。预训练提供可重用的推理能力；部署证据实例化特定问题的预测，而无需更新任一模型的神经参数。工具判断、候选人偏好和推理评估共享一个证据和查询界面，预测通过决策规则映射到选择。该架构建立了代理能力的互补来源：通过语言预训练获得的语义知识和通过结构化数据预训练获得的经验推理。单个冻结的 LimiX-2 预测器可服务于所有五个任务类别。使用 Qwen3.5-27B 作为语义编码器，DPDM 将 50 个基准测试的平均准确度从几次提示的 78.80% 提高到各自评估的历史预算下的 84.92%，并在相同的历史和查询下达到 82.33%。在 ToolPRMBench 的 BFCL 和 ToolSandbox 任务上，在方法各自评估的历史预算下，绝对精度增益分别为 34.26% 和 28.87%。随着历史的增长，准确性会提高。在相同的不平衡历史记录下，五个推理步骤评估任务和四个编码器的平均平衡精度绝对提高了 14.51%。 DPDM 使从经验中学习成为一种可独立改进的基础模型能力，为条件预测的进步创建共享路径，以改进跨代理任务的决策。

SwarmEvolve：用于进化发现和优化的潜在代理群

LLM 引导的进化搜索使用 AI 代理通过迭代改进数学和计算问题的程序

LLM 引导的进化搜索使用 AI 代理，通过迭代改进解决方案并结合高分方法来改进数学和计算问题的程序。然而，这个过程通常很慢，因为法学硕士每轮都会生成很长的文本思想链，并且必须多次重复这一生成以保持群体多样性。我们提出了 SwarmEvolve，这是一个框架，其中每轮数百个低成本代理以群体的形式工作，在潜在空间中进行推理而无需解码为文本，并通过传递 KV 缓存来共享信息。每个群体从不同的角度研究问题。新奇过滤器通过直接测量代理隐藏状态向量之间的距离来保留最独特的代理想法。思想的交叉在潜在空间中自然发生，因为摘要器代理接收所有群体成员的组合 KV 缓存。在数学发现和科学计算的 21 个问题上，SwarmEvolve 获得了最高的平均分数，并且只需要 3 到 8 分钟的中位数即可达到其他最先进框架在 60 分钟内达到的最佳分数。在几个问题上，SwarmEvolve 与 Qwen3 8B 改进了 AlphaEvolve 首次通过前沿 LLM 找到的解决方案。我们的工作表明，在潜在空间中进行通信的代理群为科学问题的程序搜索提供了一种快速、低成本的方法。

可靠的机器人操作需要语义理解和三维空间中的精确控制。豪维

可靠的机器人操作需要语义理解和三维空间中的精确控制。然而，视觉语言动作（VLA）基础很大程度上继承了 2D 视觉语言预训练的视觉表示，而空间监督通常仅在特定任务的适应过程中引入。因此，将空间理解发展为可转移的基础模型能力需要从更广泛的机器人经验中学习。我们提出了 SLA，一种空间语言动作模型，它将隐式空间对齐扩展到持续的预训练，并在下游训练后保持它。 SLA 从预训练的 pi05 策略初始化，联合优化动作预测以及中间视觉嵌入和来自冻结 3D 感知模型的空间表示之间的对齐。我们整理和统一异构机器人数据集，以支持跨不同实施例、任务和场景的空间学习。为了适应这种多样性，我们引入了特征相关的门，它自适应地聚合来自多个 VLA 层的视觉嵌入以进行空间监督。教师进一步利用部分可用的深度和相机校准以及 RGB 观察，从而有效地使用异构几何注释。概率状态丢失鼓励对视觉线索的依赖，并减轻对演示轨迹的过度拟合。所有辅助组件仅在训练期间使用，允许直接重用预训练的 VLA 权重并保留原始推理架构。
