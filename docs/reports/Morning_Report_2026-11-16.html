SO-Arena：对系统一模型的能力范围和可靠性进行基准测试

System One 模型承诺快速、通用的决策，无需冗长的代币生成。然而，理解

System One 模型承诺快速、通用的决策，无需冗长的代币生成。然而，了解他们的能力范围和决策可靠性需要的不仅仅是当前基准的总体性能。现有的评估通常对模型功能的广度及其决策的可靠性提供有限的了解。我们推出 SO-Arena，这是一个基准，描述了跨 11 个领域和 5 个功能系列的 System One 模型的能力范围和决策可靠性。对于能力范围，SO-Arena 通过可靠的来源和针对模型可见输入的参考标签的手动验证来提供基于证据的评估；通过特定领域的难度标准进行细粒度的能力评估；以及现实的交互式评估，其中模型在沙箱中迭代执行操作。推理密集型任务进一步支持系统一二比较。除了准确性之外，SO-Arena 通过两种补充措施来评估决策可靠性：受控选项集变化下的决策稳定性以及没有有效选项可用时的缺失答案识别。对 21 个模型的评估表明，扩展和附加推理的好处在不同领域存在很大差异。更重要的是，强劲的整体性能并不一定意味着可靠的决策：性能最好的 System One 模型在可靠性方面仅排名第七。总之，这些发现强调需要将能力范围和决策可靠性描述为互补维度，从而提供系统一模型的优势和局限性的系统视图。

更多基因，更快推理：根据组织学进行高效的大面板空间转录组学预测

来自组织学的空间转录组学 (ST) 预测旨在直接推断空间解析的基因表达谱

组织学的空间转录组学 (ST) 预测旨在直接从组织图像推断空间解析的基因表达谱。这是一个具有挑战性的问题，目前通常通过复杂的模型架构、额外的输入和复杂的训练程序来解决，同时仍然局限于固定的小型基因组。这就提出了一个自然的问题：是否有一种有效的大面板 ST 预测方法？在这里，我们提出了 GeneFlow，一个更简单但有效的大规模空间基因表达预测框架，它将流匹配生成模型与结构化多模态融合结合起来。具体来说，GeneFlow 首先通过组织学和基因标记器对空间点的组织学形态和跨基因相互作用进行编码。该模型直接预测空间基因表达，而不是中间速度场，同时使用基于速度的流匹配目标进行训练。我们表明，即使不依赖大量的生成管道，GeneFlow 也能在多个 ST 基准测试中实现最先进的性能，在 1,000 个基因预测中提升高达 56.8%。大量实验进一步表明，GeneFlow 可以生成具有生物学意义的点图谱，同时将计算成本降低几个数量级，从而提高效率和可扩展性，特别是在临床环境中。我们相信 GeneFlow 为利用广泛可用的组织学图像进行下游生物学发现提供了机会。代码位于：https://github.com/ZZhangsm/GeneFlow

BirdDreams：联合视角和 BEV 视频生成，打造合理的反应式驾驶世界模型

驾驶世界模型旨在模拟场景在不同的自我行为下如何展开。这需要合理的运动

驾驶世界模型旨在模拟场景在不同的自我行为下如何展开。这需要周围车辆的合理运动以及精确的自我轨迹控制。仅从透视视频学习车辆运动具有挑战性，因为运动与外观纠缠在一起，并且车辆可能被遮挡。因此，之前的工作将视频生成置于指定车辆运动的布局上，提供对周围车辆的控制，但需要它们未来的轨迹作为输入。我们引入了 BirdDreams，这是一种自回归驾驶世界模型，可联合生成透视视频和示意性鸟瞰 (BEV) 视频，使场景布局成为预测未来的一部分。 BEV 根据训练场景注释进行渲染，将道路和车辆描绘为固定公制比例的简单形状，提供其位置和运动的自上而下视图，同时减少车辆之间的遮挡。相比之下，透视视频保留了 BEV 忽略的场景细节，例如交通信号和物体外观。两个视频扩散变压器（每个流一个）之间的联合关注让每个流在生成过程中通知另一个流。预测的 BEV 还为自我控制提供了一个几何接口：我们沿着输入的自我轨迹平移和旋转其最新帧，并将生成的帧用作软条件，以显示如果仅自我车辆移动，场景将如何移动。据推断，BirdDreams 从单个摄像机图像生成两个视频，无需高清地图或车辆状态输入。在PhysicalAI-AV和nuScenes上，BirdDreams比之前的驾驶世界模型更忠实地遵循输入的自我轨迹，并且在没有自我动作调节的情况下生成更合理的自我运动。人类评估表明，BirdDreams 在生成真实的周围车辆行为方面优于仅透视基线。

Multi-agent systems solve complex tasks by decomposing them into subtasks, delegating the subtasks to agents, and aggregating the agents' responses using an aggregation rule. Malicious agents can manipulate the final solution by providing malicious responses to their assigned subtasks. In this paper, we first propose response manipulation attacks (ReMA), which iteratively optimize malicious responses to maximize attack effectiveness. Specifically, we formulate untargeted and targeted attacks as optimization problems and develop an approach to approximately solve these problems by iteratively refining malicious responses based on feedback from a surrogate multi-agent system. To defend against such attacks, we further propose SecMAS, a secure aggregation rule that leverages the semantic similarities among agent responses to select the response that is most consistent with a sufficiently large subset of the other responses. We theoretically establish security guarantees for SecMAS against both untargeted and targeted attacks.
